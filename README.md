# supportdetails.com

[supportdetails.com](https://supportdetails.com) is a simple page to gather useful browser and device information for support requests. 

This domain has been around since 2007 and for nearly 20 years has been used by companies like Stack Overflow, Facebook, Intuit, WordPress, and countless others (including us) as a tool for diagnosing browser and website problems with customers. After mysteriously going offline sometime in 2026, we took over the domain and brought it back as a free, open source tool. Completely free from ads and trackers.

We welcome you to fork and contribute. Let's keep this handy tool running for another 20 years!

The site is static HTML/CSS/JS and has no build step. 

The IP field uses Cloudflare's `/cdn-cgi/trace` endpoint and only works when hosted on Cloudflare.

PNG export uses html2canvas via jsDelivr.
