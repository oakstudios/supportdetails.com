# supportdetails.com

[supportdetails.com](https://supportdetails.com) is a simple page that shows browser, device, and display information useful in a support request. 

This domain has been around since 2007 and for nearly 20 years has been used by companies like Intuit, WordPress, and countless others as a tool for diagnosing browser and website problems with customers. After mysteriously going offline in 2026, we're bringing it back and making it free, open source, and ad/tracker-free.

We welcome you to fork and contribute. Let's keep this handy tool running for another 20 years!

The site is static HTML/CSS/JS and has no build step. 

The IP field uses Cloudflare's `/cdn-cgi/trace` endpoint and only works when hosted on Cloudflare.

PNG export loads html2canvas from jsDelivr.
